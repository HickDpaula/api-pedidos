# pedidos-web

Front-end React + TypeScript (Vite + Tailwind) do Mini Rastreador de Pedidos.

## Como rodar

Pré-requisito: backend em `http://localhost:8080`.

```bash
npm install
npm run dev
```

Acesse: `http://localhost:5173`

## Scripts

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Ambiente de desenvolvimento |
| `npm run build` | Checagem TypeScript + build de produção |
| `npm run preview` | Preview do build |
| `npm run lint` | ESLint |

Documentação completa do projeto (API + front): ver [README na raiz](../README.md).
